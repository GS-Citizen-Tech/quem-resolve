# Design System: Quem Resolve?

Cópia de referência (08/11/2026) do design system criado pelo Ian no Claude Design.
**Fonte da verdade:** https://claude.ai/artifact/H7gZMbBkjfYbmLw9Qf1nLr (não é o "Asfalto de vidro").
Se o design system mudar lá, esta cópia precisa ser atualizada.

- `README.md`: brand book completo, inclui o CSS pronto para Tailwind v4 + shadcn.
- `tokens.json`: todos os tokens (3 temas: claro, escuro, alto contraste).
- `bundle.css`: classes `qr-*` dos componentes.
- `componentes/`: guia de cada componente.
