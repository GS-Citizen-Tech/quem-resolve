# Logos

O símbolo é um pin de mapa com um check dentro: o lugar do problema e a certeza de quem resolve. Traço de 4,2 em grade de 64, cantos arredondados (`radius-card` proporcional).

- `qr-marca.svg` — Padrão: quadrado `brand` (#294b39) com traço branco. Use no tema claro e como favicon.
- `qr-marca-escuro.svg` — Tema escuro: quadrado #e2eee0 com traço #183725.
- `qr-marca-preto.svg` — Preto e branco (impressão, alto contraste, carimbo).
- `qr-marca-linha.svg` — Só o traço, uma tinta (#1f2622). Para marca d'água ou sobre foto clara; recolorir exige editar o SVG (não herda cor em `<img>`).
- `qr-icone-app.svg` — Ícone de app, sangrado (sem cantos): o sistema operacional aplica a máscara.

Tamanho mínimo: 20px (o check continua legível). Área de respiro: metade da altura do símbolo em volta. Nunca coloque o símbolo sobre o vidro sem o quadrado de fundo.
