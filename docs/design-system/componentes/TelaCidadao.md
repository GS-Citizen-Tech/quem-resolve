# TelaCidadao

Tela de amostra (celular) do resultado do cidadão: aplica a identidade, não é a tela final.

- Ordem de leitura: foto enviada → "Isso parece ser" + categoria em `display` → `SeloConfianca` → `CartaoVidro` com quem resolve e canal → `Botao` primário e secundário → dock.
- Botão de ouvir a resposta (alto-falante) no topo, para quem tem dificuldade de leitura.
- Nada abaixo de 16px; todos os alvos com 48px ou mais.
